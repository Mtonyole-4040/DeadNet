> **"In the digital graveyards of forgotten systems, we bring technology back to life."**

---

## 👁️‍🗨️ Overview
**DeadNet** is an **AI necromancer** that revives *dead or outdated codebases* and transforms them into modern, secure, and living systems — preserving the digital heritage of the past.

Built for the **Kiroween Hackathon 2025**, DeadNet merges **AI, creativity, and innovation** to reimagine software resurrection.  
It’s not just code conversion — it’s *digital archaeology powered by Kiro.*

---

## 💡 Inspiration
Across the world, countless organizations still rely on old technologies written in **COBOL, VB6, PHP4, and Python2** — systems that are fragile and hard to maintain.  
We wanted to ask a spooky but powerful question:

> *What if AI could bring dead code back to life?*

And so **DeadNet** was born — a mix of intelligence, creativity, and a little Halloween darkness.

---

## ⚙️ How It Works
DeadNet simulates **AI code resurrection** by:
1. Detecting legacy code patterns.
2. Automatically modernizing syntax and structure.
3. Generating a “Digital Soul Profile” — a short AI summary of what the old system was, its estimated era, upgrades, and modernization score.

---

## 🧠 Powered by Kiro
DeadNet uses **Kiro AI IDE** features conceptually:
- **Vibe Coding:** Conversational prompts to generate and clean code.  
- **Specs:** Structured resurrection workflows (defined in `/.kiro/specs.json`).  
- **Agent Hooks:** Automated tasks for file scanning and conversion.  
- **Steering Docs:** Maintain personality of the “AI necromancer.”  
- **MCP:** Extend capabilities for parsing legacy formats.

> The working prototype (in this repo) demonstrates the core concept using **HTML, CSS, and JavaScript** for fast interaction.
